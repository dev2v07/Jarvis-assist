## Статусы

- `CURRENT` — действующий источник истины.
- `HISTORICAL` — отчёт, отражающий состояние на дату создания.
- `SUPERSEDED` — заменён более новым документом; старый файл сохранён.
- `ARCHIVE` — сохранённый архивный материал.
- `REFERENCE` — справочник, ТЗ или технический материал.
