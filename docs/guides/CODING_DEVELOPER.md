# Jarvis Coding Developer

## Граница безопасности

Developer создаёт изменения только в отдельном проекте или sandbox. Перед изменением существующего проекта обязательны план, preview/diff, тестовый запуск и подтверждение. Удаление, перезапись и системные команды требуют отдельного подтверждения.

## Рабочий цикл

1. Уточнить требования.
2. Сформировать план и выбранный стек.
3. Создать изолированную структуру проекта.
4. Написать код.
5. Установить зависимости только в изолированное окружение.
6. Запустить тесты и линтеры.
7. Показать результат и ограничения.
8. Сохранить отчёт и точку отката.

## Поддерживаемые направления

Python/PySide6/FastAPI, HTML/CSS/JavaScript, PHP/WordPress, React/TypeScript, React Native и Flutter/Dart. Конкретный набор зависит от доступных инструментов и проекта.

## Текущий статус

MVP sandbox подключён через `POST /coding/sandbox/python`: код сохраняется только в `data/knowledge3/coding_projects`, запускается ограниченным Python-процессом с таймаутом до 15 секунд и возвращает stdout/stderr. Это не полноценная OS-level изоляция; для недоверенного кода потребуется отдельный контейнер/процессный sandbox.
