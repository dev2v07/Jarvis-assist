# Jarvis DAW Control

## Цель

Ассистированное управление Cubase 13 с видимыми и обратимыми действиями. Оригинальные проекты и аудиофайлы не изменяются автоматически.

## Приоритет интеграции

1. Read-only анализ проекта и доступных дорожек.
2. MIDI Remote API и driver scripts.
3. Generic Remote и Key Commands.
4. VST3-интерфейсы для информации о плагинах, не как универсальный API проекта.
5. UI automation только для видимых действий, когда штатного API недостаточно.

## Безопасный протокол

Работа с копией проекта, preview перед изменением, подтверждение значимых действий, Undo/rollback и журнал результата. Нельзя считать Cubase управляемым только потому, что он найден на диске.

## Исследование

Проверить дорожки, routing, sends/inserts, MixConsole, automation, export, VariAudio, AudioWarp, MIDI Editor и project settings именно в Cubase 13 Pro. Отдельно проверить поведение при закрытом проекте и недоступном API.

## Текущий статус

Cubase 13 обнаружен (`13.0.20`). Jarvis уже предоставляет:

- read-only инвентарь обнаруженных DAW и VST2/VST3 (`GET /knowledge/daw/plugins`);
- read-only анализ структуры проекта и аудиофайлов;
- отчёт по уровням, длительности, предполагаемым ролям дорожек и clipping;
- manifest-контрольную точку проекта без копирования и изменения исходников;
- confirmation-first план запуска DAW.

Инвентарь плагинов показывает только наличие бинарника на проверенном пути.
Загрузка, совместимость и управление параметрами внутри Cubase пока требуют
отдельного DAW-side adapter и не выдаются за проверенный факт.
