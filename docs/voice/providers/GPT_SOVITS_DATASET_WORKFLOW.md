# GPT-SoVITS: расширение датасета Jarvis

Новые записи складываются в `backend/voice_engine/dataset/external_jarvis_staging`.
Скрипт `tools/prepare_gpt_sovits_dataset.ps1` только собирает материал и не
перезаписывает существующие файлы.

Для каждой будущей фразы нужны:

- короткий чистый WAV без музыки и длинной тишины;
- одна фраза длительностью примерно 1–8 секунд;
- точная русская расшифровка, предоставленная пользователем;
- отсутствие дублей с другой записью того же текста.

После получения материала выполняются отдельные этапы: проверка длительности,
приведение к 32 кГц mono, сегментация, ручная сверка текста и только затем
обновление GPT‑SoVITS metadata. Исходный датасет и предыдущий checkpoint не
перезаписываются.

Не добавляй в обучение длинный исходный файл целиком: его сначала нужно
разрезать по фразам. Дубликаты оставляем только при заметно различающейся
интонации.
