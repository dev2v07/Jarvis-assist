# JARVIS ASSISTANT — UX & VOICE 2.0

## Состояние

Работа выполняется в ветке `codex/assistant-ux-voice-2`. Изменения ограничены UX/voice-слоем. `data/knowledge3`, `data/offline_knowledge`, `data/voice_responses`, их индексы и WAV в этой задаче не изменялись.

## Реализовано

- Добавлен единый `VoiceSessionManager`: одновременно допускается только одна активная сессия, с источником `widget` или `chat` и привязанным `chat_id`.
- Глобальный `/voice/start` создаёт один чат для новой widget-сессии; повторные сообщения не создают новые чаты.
- Добавлены `/voice/session/start`, `/voice/session/stop` и расширен `/voice/status`.
- Голосовой runtime использует существующий `ChatStore`: финальная распознанная реплика и ответ Jarvis сохраняются в текущий чат.
- Для chat-сессии распознанные фразы принимаются без повторного wake-word; виджет и чат не владеют микрофоном одновременно.
- При переключении чатов активная chat voice-сессия завершается до смены `chat_id`.
- В composer добавлена отдельная кнопка «Голосовой чат»; существующая кнопка микрофона сохранена как режим голосовой диктовки.
- Меню вложений расширено группой инструментов: контроль ПК, контроль браузера, Figma, плагины. Нереализованные интеграции обозначены честными точками подключения; произвольное выполнение Windows-команд не добавлялось.
- Добавлена заглушка плагинов с сообщением «Система плагинов находится в разработке».
- Добавлена кнопка полноэкранного режима между сворачиванием и закрытием, использующая `frontend/assets/полноэкранный.svg`, с возвратом к предыдущей геометрии.

## Ручная проверка

После запуска приложения проверить:

1. В новом чате нажать кнопку голосового чата и произнести две реплики без повторного «Jarvis».
2. Убедиться, что обе реплики появились в истории и сохранились после повторного открытия чата.
3. Пока chat voice активен, попробовать включить глобальный виджет — вторая сессия не должна стартовать.
4. Переключить чат — текущая voice-сессия должна завершиться без записи в новый чат.
5. Проверить диктовку отдельной кнопкой микрофона.
6. Проверить меню инструментов и полноэкранную кнопку.

## Ограничения

- Полноценная браузерная автоматизация и OAuth Figma остаются точками подключения, а не имитацией готовых интеграций.
- Микрофон/STT/TTS требуют ручной проверки на конкретном устройстве Windows.
- На момент ручного запуска порт `8000` занят ранее запущенными backend-процессами старой версии: новые маршруты требуют контролируемого перезапуска именно Jarvis backend перед проверкой голосового чата.

## Дополнительное исправление после ручного запуска

- Исправлен критический конфликт Silero VAD: поток передавал `4000` сэмплов вместо допустимых `512` при 16 кГц. Для нового размера сохранено окно тишины около 1,28 секунды.
- Длинный TorchScript traceback больше не выводится в status widget; показывается короткая причина, а Vosk остаётся fallback.
- В widget mode нативные кнопки окна принудительно скрываются после restore/fullscreen-переходов.
- Проверка `SileroVAD` на 512-сэмпловом кадре — PASS.
- Реальный API smoke test `/voice/session/start` → status → `/voice/session/stop` с выключенным микрофоном — PASS; `last_error` пустой, conversation worker запущен.
