# Offline Knowledge Library — текущий статус

Дата подготовки: 2026-11-14

## Что подготовлено

- Из прикреплённого расширения извлечён отдельный каталог из **403 тем**. В него попали только вопросы из разделов знаний, историй и лекций; процедурные пункты ТЗ исключены.
- Каталог сохранён в `data/offline_knowledge/catalog.json` и не изменяет `data/voice_responses/questions.json`, существующие тексты или WAV.
- Для каждой темы предусмотрены поля `text`, `sources`, `category`, `variants_count`, `answers`, `audio_status` и `status`.
- Текущие записи имеют статус `AUDIO_PENDING`: вопрос зарегистрирован, но проверенный материал и аудио ещё не подготовлены.
- Каталог прошёл структурную проверку: дублирующихся идентификаторов и обязательных полей не обнаружено.
- Подготовлен проверочный пилот из 3 материалов и 30 текстовых вариантов: Intel 8086, Intel 80386 и история Fender Stratocaster. Для пилота добавлены источники и статус `TEXT_READY`; аудио пока не запускалось.
- Пилотная генерация выполнена: **27 из 30** WAV созданы и прошли проверку длительности/частоты/каналов; 3 варианта получили временный `SSLEOFError` Fish Audio.
- Пользователь выполнил ручное прослушивание и подтвердил хорошее качество пилотных WAV.
- `OfflineKnowledgeService` подключён перед динамическим LLM-маршрутом. Он возвращает только записи с непустым проверенным `answers`; незавершённые темы автоматически проходят дальше к Ollama.
- Добавлен endpoint диагностики `GET /voice/knowledge`.

## Статусы материалов

Используются следующие статусы:

- `TEXT_READY` — текст подготовлен;
- `AUDIO_PENDING` — материал есть, аудио ещё не сгенерировано;
- `AUDIO_READY` — аудио создано и прошло проверку целостности;
- `VERIFIED` — текст, источники и аудио проверены;
- `ERROR` — ошибка подготовки или генерации.

Пустая строка в `answers` не считается готовым ответом и не может попасть в голосовой runtime.

## Порядок ответа

1. Существующая Conversational Library и её готовые WAV.
2. Offline Knowledge Library — только `VERIFIED`/проверенные ответы.
3. Локальный router, Ollama или профильный поиск для динамической информации.

Текущий генератор Fish Audio продолжает работать отдельно. Массовая генерация новой базы намеренно не запускалась, чтобы не конкурировать за API, CPU, диск и очередь аудио.

- Добавить 10 вариантов только для действительно утверждённых тем.
- Создать отдельный возобновляемый генератор аудио для Offline Knowledge Library.
- Добавить длинные истории и лекции отдельными материалами с управлением «продолжи/пауза/останови».
- Провести проверку WAV, длительности, размера, дубликатов и часов контента.

Добавлен возобновляемый скрипт `backend/knowledge/generate_offline_voice_library.py`. Он пропускает темы без проверенных вариантов текста и не может случайно начать массовую генерацию на пустом каталоге.

Пилотный запуск аудиогенерации будет отдельным согласуемым шагом после проверки текста; он не конкурирует с Conversational Library.

Целевой объём 1–2 ГБ рассматривается как результат качественного контента, а не как причина искусственно раздувать файлы.
